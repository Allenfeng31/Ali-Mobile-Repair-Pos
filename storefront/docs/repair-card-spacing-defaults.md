# Repair Card Spacing Defaults

This file records the default inner spacing for Ali Mobile repair-detail cards.

## Current default

- Card inner left padding: `50px`
- Card inner right padding: `50px`
- Card inner top padding: `50px`
- Card inner bottom padding: `50px`

## Tailwind default

Use this as the default card padding:

```tsx
className="px-[50px] py-[50px]"
```

## Applies to

- `CommonRepairProblemsSection`
- `WhyChooseUsSection`

## Rule

Unless a future design task explicitly overrides it, the default inner spacing for repair-detail cards should remain `50px` on all four sides.
